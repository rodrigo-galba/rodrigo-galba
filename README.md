## Research & Experiments

I am currently exploring topics around **AI agent infrastructure and evaluation**, including:

- agent behavior under different harnesses and tool configurations;
- local language models used as coding and infrastructure agents;
- context size, quantization, throughput, and hardware constraints;
- sandboxed and offline execution environments;
- Kubernetes-based operational scenarios for agents;
- reproducibility across model, context, tool, and infrastructure configurations.

The goal is to move beyond isolated agent demos and toward **repeatable, inspectable experiments** that can be compared across multiple system configurations.
